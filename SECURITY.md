# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately, using **"Report a vulnerability"** on this
repository's **Security** tab (GitHub private vulnerability reporting). Only the
maintainers and you can see the report.

Do not report vulnerabilities in public issues.

A useful report includes:

- the affected version, or the date you used the hosted build;
- the steps to reproduce, and what an attacker can do with the issue;
- your browser and its version.

Do not include API keys, the URLs of your servers, or other personal information.
Use placeholder values instead.

## Scope

In scope:

- the source code in this repository;
- the build of KisaraUI that Usegrid institute hosts.

Out of scope (please report these to their own projects):

- ComfyUI, its custom nodes, and the ComfyUI frontend;
- LLM servers and API services that you connect KisaraUI to;
- the configuration of your own servers, such as exposing ComfyUI to a network
  without authentication.

## Other questions

For bugs that are not vulnerabilities, and for feature requests, open a public issue.
For questions and other feedback, use the contact form (https://contact.kisara-ui.com).
