1. 基本方针
Usegrid institute（以下称"我方"）不在 KisaraUI（以下称"本应用"）中设置收集用户个人信息的机制。本应用没有我方的服务器，也不在界面中加入访问分析、广告或追踪机制。我方处理的仅限于分发提供方代我方记录并汇总的分发日志（见第 6 条）以及通过咨询和举报发送的内容及其附带的文件（见第 11 条）。除法律规定的情形外，我方不向第三方提供或出售用户的信息。本应用不面向未满 18 岁或未达到所在地区成年年龄的人士。如得知通过咨询收到了此类人士的信息，我方将予以删除。

2. 保存在设备上的信息
连接目标的 URL、工作流、对话、预设、头像、设置、已获取的近似判定模型、同意条款的时间等信息保存在用户的浏览器中。我方无法读取这些信息。在浏览器设置中删除本网站的数据即可清除。用于排查故障的记录（发生的错误及其前后操作的种类）仅在页面打开期间保存在界面中。除非用户将其导出为诊断文件并发送，否则不会发送到任何地方。

3. 发送到连接目标的信息
本应用仅将输入内容、设置、图像等发送到用户指定的 ComfyUI 和 LLM 服务器与服务（包括外部云服务，以下称"连接目标"）。使用网页搜索时，搜索词和要获取的 URL 会发送到连接目标及其搜索、抓取的提供方。连接目标如何处理这些信息，以其各自的条款和政策为准。由于我方不接收用户的输入和生成内容，因此也不会将其用于训练 AI。连接目标是否将发送的内容用于训练等用途，以其条款和政策为准，请自行确认。

4. 获取近似判定模型
在对话标签页中启用近似判定时，本应用会从 Hugging Face, Inc.（以下称"Hugging Face"）的网站（huggingface.co）获取判定所用的模型。此时，IP 地址、所获取文件的 URL、浏览器类型等会发送到 Hugging Face，并按照 Hugging Face 的隐私政策处理，可能在美国等用户所在国家以外的地区处理。此获取是提供用户所启用的近似判定功能所必需的处理（对于欧盟等地的用户，属于履行合同所必需的处理）。关于 Hugging Face 如何保护向境外的传输，请查阅 Hugging Face 的隐私政策。对话内容不会发送到 Hugging Face。获取的模型保存在浏览器中，下次从浏览器中读取。

5. 在 ComfyUI 中的备份
启用备份时，连接 ComfyUI 期间，本应用会将对话、头像、预设等的备份写入用户指定的 ComfyUI 的用户文件夹（kisara/）。备份作为该 ComfyUI 的文件保存，管理该 ComfyUI 的人员以及使用同一 ComfyUI 的其他人可能可以读取。在共享服务器上，请在启用备份前确认这一点。清除浏览器数据不会删除备份，不再需要时请用户自行在 ComfyUI 一侧删除。未启用备份时，浏览器中的数据丢失后将无法恢复。重要的对话请导出后保存在自己的设备上，或备份到只有自己使用的 ComfyUI。如上所述，备份在共享服务器上时，其他人可能可以读取。

6. 分发日志
本应用的文件由 Cloudflare, Inc.（以下称"Cloudflare"）分发。为了分发和防范滥用，Cloudflare 会记录 IP 地址、访问时间、请求的 URL、浏览器类型等。我方不查看单条记录，只查看 Cloudflare 汇总的数量（请求数、各国请求数等），用于了解使用规模和保护分发。此处理基于我方的正当利益。我方只查看汇总而不查看单条记录，这些记录对于分发和防范滥用不可或缺，且属于网络服务用户通常预期的范围，因此我方判断该利益不会凌驾于用户的权利和利益之上。记录可能在美国等欧盟以外的地区处理，Cloudflare 通过欧盟-美国数据隐私框架和标准合同条款保护此类传输。记录的保留期限由 Cloudflare 决定，我方无法更改（请查阅 Cloudflare 的隐私政策）。我方查看的汇总数据，仅在 Cloudflare 管理界面可查看的期间（【期间】）内保留。欧盟等地的用户依法享有查阅、更正、删除其信息，限制处理、反对处理以及数据可携带的权利，以及向监管机构投诉的权利。

7. API 密钥的处理
本应用只在页面打开期间持有输入的 API 密钥，不会保存在浏览器中。密钥仅在向用户指定的连接目标发送请求时使用。但密钥可能被浏览器中运行的其他程序（如恶意扩展程序）读取。如需保存密钥，请使用浏览器的密码管理功能（其处理方式遵循浏览器提供方的规定）。为防密钥泄露，建议使用设置了有效期或消费上限的密钥。

8. 安全管理
对于通过咨询和举报收到的信息，我方采取将可查看者限于我方及业务委托方（处理表单和邮件转发的 Cloudflare 等）等措施，防止泄露、灭失和损毁。如通过第 11 条的联系方式询问，我方将告知措施的内容。但我方无法保证通过互联网的收发完全安全。
对于处理 API 密钥和对话的部分，本应用采取的主要措施举例如下：
・LLM 的回复不作为 HTML 解析，而是作为文字显示。
・回复中的图像不会加载，而是以链接显示。
・只能打开 http 和 https 的链接。
・通过分发设置，只允许运行从我方域名分发的程序。
・在支持的浏览器中，将字符串作为 HTML 或程序插入的操作仅限于既定的形式（Trusted Types）。
得知漏洞时将努力分发修复。即便如此，也无法排除所有风险。请勿在启用了网页搜索的对话中输入泄露后会造成困扰的信息。得知发生事故时，我方将努力在代码仓库（GitHub）上发布通知，并说明吊销密钥等必要的处理。漏洞请通过 GitHub 的非公开漏洞报告功能报告。

9. 关于信息的请求
对于我方通过咨询和举报收到的信息，信息的本人可依法要求我方告知利用目的、公开、更正、补充、删除、停止利用、消除，或停止向第三方提供。请通过第 11 条的表单联系我方。我方将在确认为本人后依法处理。保存在浏览器中的信息（见第 2 条）我方并不持有，请用户在浏览器设置中自行删除。

10. 本政策的修订
修订本政策时，将在生效日之前于本应用的界面或代码仓库（GitHub）上告知修订后的内容及生效日。对用户不利的重要修订，将在本应用的界面上再次征得用户同意。

11. 咨询
问题报告和功能请求也可以在本应用代码仓库的 GitHub Issues 中提交。该处任何人都可阅读，请勿填写个人信息、API 密钥或连接目标的 URL。一般问题、涉及个人信息的咨询、第 9 条的请求以及使用条款第7条的举报，请通过咨询表单（https://contact.kisara-ui.com）发送。请填写可接收回复的电子邮件地址。表单中填写的内容由 Cloudflare Workers 接收，并经由 Cloudflare 的邮件转发（Email Routing）以邮件形式送达我方。为抑制连续发送，发送方的 IP 地址仅在 Cloudflare 内短时间计数，不与内容一同保存。收到的联系方式和内容仅用于答复咨询和举报，处理完毕且不再需要时即予删除。
表单最多可附带 3 个文件（诊断文件、界面图像（PNG、JPEG、WebP）、文本文件；每个不超过 5 MB，合计不超过 10 MB）。诊断文件是用户从本应用的设置中导出的、用于排查故障的文件。其中包含发生的错误（内容、发生位置和堆栈跟踪）及其前后操作的记录、本应用、浏览器和所连接 ComfyUI 的版本、所用设备的种类，以及通过选项选择的设置；不包含对话、提示词、工作流的值、图像和 API 密钥。连接目标（ComfyUI 和 LLM）的 URL 默认包含，可在导出前去除。导出前可确认其全部内容。界面图像会原样包含其中显示的对话、生成内容等，请在附带前确认。附带的文件与咨询内容一样，仅用于排查故障和答复咨询，处理完毕且不再需要时即予删除。
用户信息的控制者：Usegrid institute（联系方式为第 11 项的表单）。日本《个人信息保护法》规定应使本人可知的事项，仅限于我方已收到其信息的本人提出请求时，在确认本人身份后，于法律规定的范围内处理。

12. 语言
本政策以日文版为准，其他语言版本仅为参考译文。内容不一致时，以日文版为准。
