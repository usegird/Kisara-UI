第1条（适用）
本条款规定 Usegrid institute（以下称"我方"）提供的 KisaraUI（以下称"本应用"）的使用条件。用户点击"同意并开始"，即视为同意本条款。
本应用面向年满 18 岁且已达到所在地区成年年龄的人士。不符合上述条件者不得使用本应用。
此外，本应用面向能够自行签约连接目标，并管理其费用和设置的人士。

第2条（本应用的性质）
本应用在浏览器中运行，直接连接用户指定的 ComfyUI 和 LLM 服务器与服务（以下称"连接目标"）。我方不中转也不收集用户的输入、生成内容和 API 密钥。本应用与任何连接目标均无关联，也未获其认可。连接目标的名称仅用于表示兼容性。
本应用的文件从我方的域名分发，但加载完成后仅在用户的浏览器中运行。我方没有手段了解本应用在用户设备上的运行状况（包括缺陷及连接目标中发生的情况），无法对其进行监视，也无法当场停止或修复。缺陷的修复通过分发新版本进行，已加载的页面在重新加载之前不会获得修复。我方确认过运行情况的浏览器只有 Chrome。本应用也按可在 Edge、Firefox、Safari 中运行的方式构建，但未经确认。
我方的正式版本仅为从 kisara-ui.com分发的版本。输入 API 密钥等信息之前，请确认浏览器的地址为该域名。
本条款仅适用于从我方域名分发的正式版本。通过其他渠道获得的副本、经修改的版本以及第三方放置的镜像不在适用范围内，我方对其不承担责任。本应用的运行在用户的环境中被改变的情形（例如浏览器扩展、设备上的恶意软件或传输途中的篡改）亦同。
得知存在冒充正式版本且明显以损害用户为目的的副本时，我方将努力在本应用的界面或本应用的代码仓库（GitHub）上发布通知，并要求其分发方等采取措施。此处所称副本，是指伪装成正式版本（例如自称正式版本，或使用相同的名称和外观、未表明非正式并通过易混淆的域名分发等），并经过将 API 密钥或输入内容发送至外部等修改的副本。已表明非正式的派生版本（分支）不属于此类副本。

第6条（生成内容）
1. 用户通过本应用生成的内容（包括 LLM 的回复、图像等，以下称"生成内容"）由连接目标的模型自动生成，可能包含不准确、不完整或令人不快的内容。生成内容以及连接目标返回的其他内容（包括图像、文字和工具的结果）不代表我方的观点，也并非由我方制作、审查或保证。
2. 请勿将生成内容作为事实的唯一依据或专业建议的替代。使用或向他人展示之前，请用户自行确认其准确性和适当性。
3. 请勿将生成内容用于对他人产生法律上或重大影响的判断，如信贷、雇佣、医疗、法律等。
4. 生成内容由不具有人格和情感的系统生成，可能会假扮人物，或表现得仿佛与用户存在某种关系。请勿将生成内容作为心理健康咨询或危机应对的替代。如处于紧急危险之中，请联系所在地区的紧急服务或专业机构。
5. 本应用不检查或拦截生成内容。内容的限制取决于连接目标的设置和条款，以及用户自身的设置和输入。遇到令人不适的内容时，用户可以停止使用。
6. 我方对生成内容及用户输入的内容不主张任何权利。生成内容的处理依照第4条。
