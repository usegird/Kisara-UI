1. 基本の方針
Usegrid institute（以下「当方」）は、KisaraUI（以下「本アプリ」）の中に、利用者の個人情報を集める仕組みを置きません。本アプリは当方のサーバーを持たず、画面の中にアクセス解析・広告・追跡の仕組みを入れません。当方が扱うのは、配信の提供元が当方のために記録し集計する配信の記録（6 を参照）と、問い合わせや知らせで送られた内容と、それに添えられたファイル（11 を参照）だけです。当方は、利用者の情報を第三者に提供せず、販売もしません（法令に基づく場合を除きます）。本アプリは、18 歳未満の方や、お住まいの地域の成年年齢に達していない方を対象としていません。そうした方から問い合わせで情報を受け取ったと分かったときは、その情報を消します。

2. 端末に残す情報
接続先の URL、ワークフロー、会話、プリセット、アバター、設定、取得した近似判定のモデル、規約に同意した日時などは、利用者のブラウザの中に残ります。当方はこれらを読めません。ブラウザの設定でこのサイトのデータを消すと消えます。不具合を調べるための記録（起きた失敗と、その前後の操作の種類）は、ページを開いている間だけ画面の中に持ちます。利用者が診断ファイルとして書き出して送らない限り、どこにも送りません。

3. 接続先に送る情報
本アプリは、利用者が指定した ComfyUI と LLM のサーバー・サービス（外部のクラウドのサービスを含みます。以下「接続先」）にだけ、入力した内容・設定・画像などを送ります。Web 検索を使うと、検索語や取得する URL が、接続先とその検索・取得の提供元に送られます。接続先での扱いは、それぞれの規約とポリシーに従います。当方は、利用者の入力と生成物を受け取らないため、AI の学習にも使いません。接続先が送った内容を学習などに使うかどうかは接続先の規約とポリシーに従いますので、そちらをご確認ください。

4. 近似判定のモデルの取得
会話のタブで近似判定を有効にすると、判定に使うモデルを Hugging Face, Inc.（以下「Hugging Face」）のサイト（huggingface.co）から取得します。このとき、IP アドレス・取得するファイルの URL・ブラウザの種類などが Hugging Face に届き、Hugging Face のプライバシーポリシーに従って扱われます。米国など、利用者の国の外で扱われることがあります。この取得は、利用者が有効にした近似判定の機能を提供するために必要な処理です（EU などの利用者については、契約の履行に必要な処理に当たります）。Hugging Face が国外への移転をどのように保護しているかは、Hugging Face のプライバシーポリシーでご確認ください。会話の内容は Hugging Face に送りません。取得したモデルはブラウザの中に残り、次からはそこから読みます。

5. ComfyUI への控え
バックアップを有効にしていると、ComfyUI に接続している間、会話やアバター、プリセットなどの控えを、利用者が指定した ComfyUI のユーザーフォルダ（kisara/）に書きます。控えはその ComfyUI のファイルとして残り、その ComfyUI を管理する人や、同じ ComfyUI を使うほかの人が読める場合があります。共有のサーバーでは、バックアップを有効にする前にこの点を確かめてください。ブラウザのデータを消しても控えは残るので、要らなくなったら利用者が ComfyUI の側で消してください。控えを有効にしていないと、ブラウザのデータが失われたときに元に戻せません。大切な会話は、書き出して手元に保存するか、自分だけが使う ComfyUI への控えで残してください。共有のサーバーへの控えは、上のとおりほかの人が読める場合があります。

6. 配信の記録
本アプリのファイルは Cloudflare, Inc.（以下「Cloudflare」）が配信します。Cloudflare は、配信と不正な利用への対策のために、IP アドレス・アクセスの時刻・要求した URL・ブラウザの種類などを記録します。当方は記録の一件ずつを見ず、Cloudflare が集計した件数（要求の数・国別の数など）だけを、利用の規模を知り配信を守るために見ます。これは当方の正当な利益に基づく処理です。当方は記録の一件ずつを見ず集計だけを見ること、配信と不正な利用への対策に欠かせないこと、Web サービスの利用者が通常想定する範囲の記録であることから、利用者の権利と利益を上回るものではないと判断しています。記録は米国など EU の外で扱われることがあり、Cloudflare は EU-米国データプライバシー枠組みと標準契約条項によって移転を保護しています。記録を残す期間は Cloudflare が定め、当方は変えられません（Cloudflare のプライバシーポリシーをご確認ください）。当方が見る集計は、Cloudflare の管理画面で見られる期間（【期間】）だけ残ります。EU などの利用者は、法令の定めにより、自分の情報について、確認・訂正・消去・処理の制限・処理への異議・データの持ち運び（ポータビリティ）を求める権利と、監督機関に苦情を申し立てる権利を持ちます。

7. API キーの扱い
本アプリは、入力した API キーをページを開いている間だけ持ち、ブラウザの中に残しません。キーは、利用者が指定した接続先へ要求を送るときだけ使います。ただし、悪意のある拡張機能など、ブラウザの中で動くほかのプログラムからは読み取られることがあります。キーを保存したいときは、ブラウザのパスワード管理の機能をお使いください（その扱いはブラウザの提供元に従います）。キーが漏れたときに備えて、有効期限や利用額の上限を設定したキーを使うことをおすすめします。

8. 安全管理
問い合わせや知らせで受け取った情報について、当方は、見られる者を当方と業務の委託先（フォームの処理とメールの転送を担う Cloudflare など）に限るなど、漏えい・滅失・毀損を防ぐ措置をとります。措置の内容は、11 の窓口でお尋ねいただければお答えします。ただし、インターネットを通じた送受信が完全に安全であることは保証できません。
本アプリが API キーや会話を扱う部分でとっている主な対策の例は、次のとおりです。
・LLM の応答は HTML として解釈せず、文字として表示します。
・応答の中の画像は読み込まず、リンクとして示します。
・リンクは http と https のものだけを開けるようにしています。
・配信の設定で、当方のドメインから配信するプログラムだけが動くようにしています。
・対応するブラウザでは、文字列を HTML やプログラムとして差し込む操作を、決めた形のものに限っています（Trusted Types）。
脆弱性が分かったときは修正の配信に努めます。それでも、危険をすべて取り除くことはできません。Web 検索を有効にした会話には、漏れて困る情報を入れないでください。事故が分かったときは、リポジトリ（GitHub）で知らせ、キーの無効化など必要な手当てを案内するよう努めます。脆弱性の報告は、GitHub の非公開の脆弱性報告で受け付けます。

9. 開示などの請求
問い合わせや知らせで当方が受け取った情報について、その情報の本人は、法令の定めにより、利用目的の通知・開示・訂正・追加・削除・利用の停止・消去・第三者への提供の停止を求めることができます。11 のフォームでご連絡ください。本人であることを確かめたうえで、法令に従って対応します。ブラウザの中に残る情報（2 を参照）は当方が持っていないので、ブラウザの設定から消してください。

10. このポリシーの改定
このポリシーを改定するときは、改定後の内容と効力が生じる日を、その日より前に本アプリの画面またはリポジトリ（GitHub）で知らせます。利用者に不利で重要な改定のときは、本アプリの画面で改めて同意をいただきます。

11. 問い合わせ
不具合の報告と要望は、本アプリのリポジトリの GitHub Issues でも受けます。誰でも読める場所なので、個人情報・API キー・接続先の URL は書かないでください。一般的な質問、個人情報に関わる問い合わせ、9 の請求、利用規約 第7条の知らせは、問い合わせフォーム（https://contact.kisara-ui.com）でお送りください。返事を受け取るメールアドレスを入れてください。フォームに入れた内容は、Cloudflare の Workers が受け取り、Cloudflare のメールの転送（Email Routing）を通ってメールとして当方に届きます。連続した送信を抑えるため、送信元の IP アドレスを Cloudflare の中で短い時間だけ数えます。内容と一緒には保存しません。受け取った連絡先と内容は、問い合わせと知らせに答えるためだけに使い、対応を終えて要らなくなったら消します。
フォームには、ファイルを 3 件まで添えられます（診断ファイル、画面の画像（PNG・JPEG・WebP）、文字のファイル。1 件 5 MB、合わせて 10 MB まで）。診断ファイルは、利用者が本アプリの設定から書き出す、不具合を調べるためのファイルです。起きたエラー（文面・どこで起きたか・スタックトレース）とその前後の操作の記録、本アプリ・ブラウザ・接続している ComfyUI の版、使っている機器の種類、選択肢で選ぶ設定を含み、会話・プロンプト・ワークフローの値・画像・API キーは含みません。接続先（ComfyUI と LLM）の URL は既定で含み、書き出す前に外せます。書き出す前に中身の全文を確かめられます。画面の画像には、写っている会話や生成物などがそのまま含まれますので、添える前に確かめてください。添えられたファイルは、問い合わせの内容と同じく、不具合を調べることと問い合わせに答えることだけに使い、対応を終えて要らなくなったら消します。
